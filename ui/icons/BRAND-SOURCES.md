# Harness brand assets

These are the actual application marks used in the harness picker:

- `brand-openai.svg`: OpenAI logo, sourced from the current OpenAI logo file on Wikimedia Commons.
- `brand-anthropic.svg`: Anthropic mark from the Simple Icons SVG set.
- `brand-opencode.svg`: OpenCode mark from the official OpenCode repository.
- `brand-pi.svg`: Pi Coding Agent mark from the official `pi.dev` site.

The UI uses the marks only as compact identifiers for the corresponding
harness options. They remain the property of their respective owners.
